## 🎯 优化内容

### 1. 后端文本格式化工具 ✅

**文件**：`backend-python/app/utils/text_formatter.py`

**功能**：
- `clean_markdown()` - 清理和规范化 Markdown 文本
  - 移除多余空行
  - 确保标题前后有空行
  - 规范化列表格式
  - 优化加粗标记
  
- `add_paragraph_breaks()` - 为纯文本添加段落分隔
  - 智能识别句子边界
  - 自动添加段落间隔
  - 保持原有格式

- `format_for_display()` - 统一的格式化入口
  - 自动检测文本类型
  - 应用相应的格式化策略

**代码示例**：
```python
formatter = TextFormatter()

# 清理 Markdown
cleaned = formatter.clean_markdown(llm_response)

# 格式化纯文本
formatted = formatter.add_paragraph_breaks(plain_text)
```

### 3. 三级处理流程 ✅

**文件**：`backend-python/app/services/enhanced_divination_service.py`

**流程设计**：

#### Level 1: 高质量问题 + LLM 增强
- **条件**：问题质量评分 ≥ 60 分 且 LLM 服务可用
- **处理**：完整的 LLM 增强解读
- **输出格式**：结构化 Markdown（标题、列表、加粗）
- **示例问题**："我应该在今年跳槽到新公司吗？"

#### Level 2: 高质量问题 + 无 LLM
- **条件**：问题质量评分 ≥ 60 分 但 LLM 服务不可用
- **处理**：基础算法解读
- **输出格式**：纯文本（自动添加段落）
- **示例问题**："我的事业发展方向是什么？"

#### Level 3: 低质量问题
- **条件**：问题质量评分 < 60 分
- **处理**：返回引导文本，提示用户改进问题
- **输出格式**：友好的提示信息
- **示例问题**："好不好？"

**代码实现**：
```python
async def start_divination_with_enhancement(self, request):
    # 分析问题质量
    analysis = await self.question_analyzer.analyze(request.question)
    
    if analysis.score < 60:
        # Level 3: 低质量问题
        return self._create_guidance_result(analysis)
    
    if self.llm_service:
        # Level 1: 高质量 + LLM
        result = await self._enhance_with_llm(basic_result)
        result.summary = self.formatter.clean_markdown(result.summary)
        result.detail = self.formatter.clean_markdown(result.detail)
    else:
        # Level 2: 高质量 + 无 LLM
        result.summary = self.formatter.add_paragraph_breaks(result.summary)
        result.detail = self.formatter.add_paragraph_breaks(result.detail)
    
    return result
```

### 5. CSS 样式优化 ✅

**文件**：`web/src/components/divination/DivinationResultCard.css`

**优化内容**：

#### 基础排版
- 字体大小：15-16px（移动端 14px）
- 行高：1.9-2.0（提升可读性）
- 字间距：0.3px（优化视觉效果）

  border-radius: 4px;
}

  margin-bottom: 10px;
  line-height: 1.8;
}

/* 引用块 */

  border-left: 4px solid #667eea;
  padding: 12px 16px;
  background: rgba(102, 126, 234, 0.05);
  border-radius: 0 8px 8px 0;

- **桌面端**（≥ 1024px）：字体 16px，行高 2.0，最大宽度 800px
