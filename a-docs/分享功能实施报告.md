
**磁盘使用情况**：
```

/dev/vda3       118G  114G     0   100%  /
```

**影响**：
- PostgreSQL 无法启动
- 数据库迁移无法执行
- 后端服务无法正常运行

**建议解决方案**：

1. **清理 Docker 资源**
   ```bash
   docker system prune -a --volumes
   docker image prune -a
   ```

2. **清理日志文件**
   ```bash
   find /var/log -type f -name "*.log" -mtime +7 -delete
   journalctl --vacuum-time=7d
   ```

3. **清理临时文件**
   ```bash
   rm -rf /tmp/*
   rm -rf /var/tmp/*
   ```

4. **检查大文件**
   ```bash
   du -h / | sort -h | tail -20
   ```
