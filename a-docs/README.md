## 🗂️ 文档使用指南

### 新成员入门

1. 先读 `design/ARCH_AND_DESIGN.md` 了解整体架构
2. 根据需要查阅具体的设计文档和实施报告

### 开发新功能

1. 查阅 `design/ARCH_AND_DESIGN.md` 确保符合整体架构
2. 参考相关的实施报告了解已有功能的实现方式

### 设计评审

1. 对照 `design/ARCH_AND_DESIGN.md` 检查架构一致性
2. 参考已完成的实施报告了解设计模式

## 📝 文档维护规范

### 文档分类原则

- **design/** - 架构设计、功能设计、系统设计
- **plan/** - 实施计划、完成报告、状态分析

### 文档命名规范

- 设计文档：`功能名_design.md` 或 `UPPERCASE_NAME.md`
- 实施报告：`功能名实施完成报告.md` 或 `YYYY-MM-DD_description.md`
