## 📝 使用说明

### 访问用户管理
1. 登录管理后台：http://localhost:40081/admin/login
2. 使用管理员账号登录（admin / 594120）
3. 点击侧边栏"用户管理"或首页"用户管理"卡片

### 核心操作流程

#### 创建用户
1. 点击"新建用户"按钮
2. 填写用户信息（用户名、密码、角色等）
3. 系统自动验证唯一性
4. 提交创建

#### 编辑用户
1. 在用户列表中点击"编辑"按钮
2. 修改用户信息
3. 系统自动验证（排除自己）
4. 提交更新

#### 批量操作
1. 勾选要操作的用户
2. 批量操作栏自动显示
3. 选择操作（启用/禁用/删除）
4. 确认执行

#### 搜索筛选
1. 在搜索框输入关键词
2. 展开高级筛选面板
3. 选择筛选条件
4. 点击"应用筛选"

## 🔒 安全建议

### 生产环境必须修改
1. **JWT 密钥** - 修改 `JWT_SECRET` 环境变量
2. **数据库密码** - 修改 `POSTGRES_PASSWORD`
3. **管理员密码** - 首次登录后立即修改
4. **使用 HTTPS** - 配置 SSL 证书

### 权限控制
- 所有用户管理 API 都需要管理员权限
- 不能删除或修改超级管理员
- 不能修改自己的关键信息
