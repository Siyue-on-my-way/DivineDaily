# ChatGPT Tarot Divination 项目业务能力分析报告

## 一、项目概述

这是一个基于 **ChatGPT** 的 AI 占卜应用，采用 **FastAPI + React** 架构，支持多种传统占卜方式，提供流式输出体验和历史记录管理。

### 技术栈
- **后端**: Python 3.8+, FastAPI, OpenAI API
- **前端**: React 18, TypeScript, Vite, Tailwind CSS
- **部署**: 支持 Vercel、Docker、本地运行、Tauri 桌面应用

---

## 二、核心业务能力

### 1. 占卜功能模块（7种占卜方式）

#### 1.1 塔罗牌占卜 (Tarot)
- **功能**: 通过虚拟塔罗牌进行占卜
- **输入**: 用户问题（最多40字）
- **处理逻辑**:
  - 系统提示词要求 AI 担任塔罗占卜师角色
  - 要求洗牌并抽3张随机卡
  - 解释每张卡的意义（过去/现在/未来）
  - 结合问题给出建议
- **实现文件**: `src/divination/tarot.py`

#### 1.2 生辰八字 (Birthday)
- **功能**: 根据出生时间分析命理运势
- **输入**: 生日时间（格式: `YYYY-MM-DD HH:mm:ss`）
- **处理逻辑**:
  - 系统提示词要求 AI 担任中国传统生辰八字算命师
  - 分析五行属性、吉凶祸福、财运、婚姻、健康、事业
  - 提供相应指导和建议
- **实现文件**: `src/divination/birthday.py`

#### 1.3 姓名五格 (Name)
- **功能**: 通过姓名笔画分析性格和命运
- **输入**: 姓名（1-10字）
- **处理逻辑**:
  - 系统提示词要求 AI 担任姓名五格算命师
  - 分析姓氏格、名字格、自己格
  - 提供指导和建议
- **实现文件**: `src/divination/name.py`

#### 1.4 周公解梦 (Dream)
- **功能**: 解析梦境含义，探索潜意识
- **输入**: 梦境描述（最多40字）
- **处理逻辑**:
  - 系统提示词要求 AI 担任周公解梦师
  - 解释梦境并提供指导建议
- **实现文件**: `src/divination/dream.py`

#### 1.5 起名取名 (New Name)
- **功能**: 根据生辰八字和五行推荐吉祥名字
- **输入**: 
  - 姓氏
  - 生日时间
  - 性别
  - 额外要求（可选，最多20字）
- **处理逻辑**:
  - 系统提示词要求 AI 担任起名师
  - 结合姓氏、生日、性别等信息
  - 返回最适合的名字（姓氏在前，名字在后）
- **实现文件**: `src/divination/new_name.py`

#### 1.6 梅花易数 (Plum Flower)
- **功能**: 传统易学占卜方法
- **输入**: 两个数字（num1, num2）
- **处理逻辑**:
  - 系统提示词要求 AI 担任梅花易数占卜师
  - 第一个数取为上卦，第二个数取为下卦
  - 直接以数起卦并解释结果
- **实现文件**: `src/divination/plum_flower.py`

#### 1.7 姻缘占卜 (Fate)
- **功能**: 分析感情运势和姻缘走向
- **输入**: 两个人的名字（name1, name2，各最多40字）
- **处理逻辑**:
  - 系统提示词要求 AI 担任姻缘助手
  - 判断人名真实性（如张三李四返回不合适）
  - 判断性别（同性返回不合适）
  - 90%概率说合适，10%概率说不合适并说明原因
- **实现文件**: `src/divination/fate.py`

### 2. 占卜工厂模式 (Factory Pattern)

项目使用**元类（Metaclass）**实现工厂模式，自动注册所有占卜类型：

```python
class MetaDivination(type):
    divination_map = {}
    
    def __init__(cls, name, bases, attrs):
        super().__init__(name, bases, attrs)
        if hasattr(cls, 'divination_type'):
            MetaDivination.divination_map[cls.divination_type] = cls
```

**特点**:
- 每个占卜类继承 `DivinationFactory`
- 通过 `divination_type` 属性自动注册
- 通过 `DivinationFactory.get(type)` 获取实例
- 所有占卜类实现 `build_prompt()` 方法，返回 `(user_prompt, system_prompt)` 元组

**实现文件**: `src/divination/base.py`

### 3. AI 流式输出能力

#### 3.1 后端流式响应
- 使用 OpenAI 的 `stream=True` 参数
- 返回 `StreamingResponse`，媒体类型为 `text/event-stream`
- 每个数据块格式: `data: {json.dumps(content)}\n\n`
- **实现文件**: `src/chatgpt_router.py`

#### 3.2 前端流式接收
- 使用 `@microsoft/fetch-event-source` 库
- 实时解析 SSE 数据流
- 使用 `markdown-it` 实时渲染 Markdown 内容
- 打字机效果展示结果
- **实现文件**: `frontend/src/hooks/useDivination.ts`

**关键代码流程**:
```typescript
await fetchEventSource('/api/divination', {
  onmessage(msg) {
    const newContent = JSON.parse(msg.data)
    tmpResultBuffer += newContent
    setResult(md.render(tmpResultBuffer))  // 实时渲染
  }
})
```

### 4. 历史记录管理

#### 4.1 存储机制
- **存储位置**: 浏览器 `localStorage`
- **存储格式**: 按占卜类型分开存储
- **存储键名**: `divination_history_{type}`
- **最大记录数**: 每种类型保留最近 10 条

#### 4.2 数据结构
```typescript
interface DivinationHistoryItem {
  id: string           // 唯一ID: timestamp-random
  type: string         // 占卜类型
  title: string        // 占卜标题
  prompt: string       // 用户输入
  result: string       // AI 返回结果
  timestamp: number     // 时间戳
}
```

#### 4.3 功能
- **保存**: 占卜完成后自动保存
- **查看**: 支持按类型查看历史记录
- **删除**: 支持删除单条或清空所有记录
- **实现文件**: `frontend/src/utils/divinationHistory.ts`, `frontend/src/pages/History.tsx`

---

### 5. 用户认证与限流

#### 5.1 GitHub OAuth 登录
- **流程**: 
  1. 前端跳转到 GitHub OAuth 授权页面
  2. 用户授权后返回 code
  3. 后端用 code 换取 access_token
  4. 获取用户信息，生成 JWT token
  5. Token 有效期 30 天
- **实现文件**: `src/user_router.py`, `src/user.py`

#### 5.2 速率限制 (Rate Limiting)
- **未登录用户**: 默认 `60请求/3600秒`
- **已登录用户**: 默认 `600请求/3600秒`
- **实现方式**: 
  - 支持内存缓存、Redis、Upstash KV
  - 基于 IP 地址或用户 ID 限流
- **实现文件**: `src/limiter.py`, `src/cache/`

#### 5.3 自定义 API 配置
- 支持通过请求头自定义 OpenAI 配置:
  - `x-api-key`: 自定义 API Key
  - `x-api-url`: 自定义 API 地址
  - `x-api-model`: 自定义模型名称
- **实现位置**: `src/chatgpt_router.py`

## 三、API 接口设计

### 核心接口

#### 1. POST `/api/divination`
**功能**: 执行占卜请求

**请求体**:
```json
{
  "prompt": "用户输入的问题",
  "prompt_type": "tarot|birthday|name|dream|new_name|plum_flower|fate",
  "birthday": "2000-08-17 00:00:00",  // 可选
  "new_name": {                        // 可选
    "surname": "张",
    "sex": "男",
    "birthday": "2000-08-17 00:00:00",
    "new_name_prompt": "要求"
  },
  "plum_flower": {                     // 可选
    "num1": 5,
    "num2": 8
  },
  "fate": {                           // 可选
    "name1": "张三",
    "name2": "李四"
  }
}
```

**响应**: SSE 流式响应 (`text/event-stream`)

#### 2. GET `/api/v1/settings`
**功能**: 获取系统设置信息

**响应**:
```json
{
  "login_type": "github",
  "user_name": "username",
  "rate_limit": "60req/3600seconds",
  "user_rate_limit": "600req/3600seconds",
  "ad_client": "",
  "ad_slot": "",
  "enable_login": true,
  "enable_rate_limit": true,
  "default_api_base": "https://api.openai.com/v1",
  "default_model": "gpt-3.5-turbo",
  "purchase_url": ""
}
```

#### 3. GET `/api/v1/login`
**功能**: 获取登录 URL

**参数**: 
- `login_type`: 登录类型（如 "github"）
- `redirect_url`: 回调地址

#### 4. POST `/api/v1/oauth`
**功能**: OAuth 回调处理

**请求体**:
```json
{
  "login_type": "github",
  "code": "oauth_code"
}
```

**响应**: JWT token 字符串

## 四、数据流设计

### 占卜请求流程

```
用户输入
  ↓
前端验证（长度、格式）
  ↓
POST /api/divination
  ↓
后端验证（停止词、参数）
  ↓
速率限制检查
  ↓
DivinationFactory.get(type) 获取占卜实例
  ↓
build_prompt() 构建提示词
  ↓
调用 OpenAI API (stream=True)
  ↓
SSE 流式返回
  ↓
前端实时接收并渲染
  ↓
保存历史记录（localStorage）
```

## 五、配置管理

### 环境变量配置

**必需配置**:
- `api_key`: OpenAI API Key

**可选配置**:
- `api_base`: API 地址（默认: `https://api.openai.com/v1`）
- `model`: 模型名称（默认: `gpt-3.5-turbo`）
- `github_client_id`: GitHub OAuth Client ID
- `github_client_secret`: GitHub OAuth Client Secret
- `jwt_secret`: JWT 密钥（默认: `secret`）
- `rate_limit`: 速率限制（格式: `60,3600`）
- `user_rate_limit`: 用户速率限制（格式: `600,3600`）
- `cache_client_type`: 缓存类型（`memory|redis|upstash`）
- `redis_url`: Redis 连接 URL
- `upstash_api_url`: Upstash API URL
- `upstash_api_token`: Upstash API Token
- `ad_client`: Google Ads 客户端 ID
- `ad_slot`: Google Ads 广告位

**实现文件**: `src/config.py`
